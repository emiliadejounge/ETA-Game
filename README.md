# Searcher: Buy a Business

A 5–10 minute choose-your-path game about Entrepreneurship Through Acquisition. Players go from MBA graduation through funding a search, sourcing, meeting the seller, the LOI, due diligence, running the company, and the exit. Every decision teaches a takeaway from the course pre-readings.

Made by Emilia de Jounge for **MGT 4455 Entrepreneurship Through Acquisition** (Prof. Doug Villhard).

## Play
Open `index.html` in a browser. No build step needed.

## Host on GitHub Pages
1. Create a new public repository on GitHub and upload `index.html` (and this README).
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` / `(root)`, and save.
3. After about a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.
